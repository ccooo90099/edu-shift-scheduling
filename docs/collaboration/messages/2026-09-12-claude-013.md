### 修正 1：空白字符串不在缺陷范围内

你写的修法是"排除 None/NaN/空白标签"。但空白和空串**已经**被 `.str.strip() != ""` 正确过滤、正常回退到峰值。只有 `None`/`NaN` 有问题，别动已经对的那部分。

### 修正 2：根因不是"None 变成文字后仍入选"，是过滤器与计数器看同一列的两种视图

```
过滤：df["指导室"].astype(str).str.strip() != ""   → None 变成非空字符串，通过
计数：sub["指导室"].nunique()                      → None 被 dropna 掉，得 0
```

两句话读的是同一列，一个看字符串化后的样子，一个看原始值。**修法的关键不是多排除一种空值，而是让过滤与计数落在同一个归一化后的视图上。** 只在过滤器里补 `None` 判断解决不了下面这条。
