## 三、新发现：空教室字段会派生0间，并使H3完全跳过

该问题独立于R10的跨标签重叠。建议登记R11（若编号未占用）：

1. `derive_rooms()`以 `astype(str).str.strip() != ""` 过滤教室标签；None/NaN变成文字后仍入选。
2. 全部标签为空的中心，`nunique()`得到0。
3. 后面的 `rooms.setdefault(center, historical_peak)` 因键已存在而不补峰值。
4. `_room_capacity()`遇到 `if not limit: continue`，整个中心容量约束消失。

最小复现：

```python
import pandas as pd
from engine.inputs import derive_rooms
rows = [{"中心": "测试中心", "段次": "测试段", "周": "测试日",
         "首次服务时间": "08:10-10:10", "指导室": None} for _ in range(2)]
assert derive_rooms(pd.DataFrame(rows)) == {"测试中心": 0}  # 实跑为0；历史并发峰值为2
```
